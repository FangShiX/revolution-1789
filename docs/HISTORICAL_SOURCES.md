# 历史资料与原创叙事

公开版故事为原创：玩家是一名能写字的记录者。工作、会面、信件、证词、具体委托和个人结局均为虚构。玩家影响个人道路，不控制真实历史事件。54个节点沿不同选择分支汇合，十种结局分别呈现流亡、地方生活、登记、军中通信、文书保存、死亡、海港记录、修书、公职与教学等经历。

历史事实依据凡尔赛宫、法国国民议会和爱丽舍宫的公开档案，节点中的史实注解链接至相关具体页面。完整来源清单与各节点 sourceIds 见 `src/data/publicCampaign.js`。引用采用短篇原创转述，没有复制这些网站的长篇正文。

核查重点：1789年5月5日三级会议、6月17日国民议会、6月20日网球厅宣誓、7月14日起义；1791年宪法与政治资格限制；1792年8月暂停国王职权与9月废除王政的区别；国王12月11日到庭与1793年1月21日处决；1794年2月4日废奴、法令与实施的区别；热月与督政府、雾月政变。

涉及妇女、宗教分裂、奴役和政治暴力时，叙事避免把复杂历史归功于虚构玩家，也不把个人结局视作对阵营的道德评分。结局206涉及虚构个人死亡，不含图像化暴力描写。

原书在私人模式中仍有独立校勘和文本来源记录，不作为公开剧情的文字来源。公开原创新增内容与原书改编数据不能混为一个授权范围。
